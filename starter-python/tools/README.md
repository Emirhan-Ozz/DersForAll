# Soru ve özet kaynakları

- `q01.py` … `q10.py`: her konunun 25 sorusu (part(1) = Test 1, part(2) = Test 2).
- `content.py`: konu özetleri, tuzaklar, kurallar.
- `python3 check.py q01 q02 … q10`: her soruyu gerçek Python 3 ile çalıştırıp doğrular.
- `python3 build.py ..`: özetlerdeki kodları da doğrular, `../content.js` ve `../questions.js` dosyalarını üretir.
